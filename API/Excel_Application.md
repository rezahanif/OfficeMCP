# Application.Visible

## Syntax
expression.Application.Visible = True/False

## Description
Shows or hides the Excel application window.

# Application.Quit

## Syntax
expression.Application.Quit

## Description
Quits Excel. Unsaved workbooks prompt unless DisplayAlerts = False first.

# Workbooks.Open

## Syntax
expression.Application.Workbooks.Open(FileName)

## Description
Opens a workbook file and returns a Workbook object.
